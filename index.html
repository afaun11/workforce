Aturan Keamanan Firebase Rules (Aman & Aktif Selamanya)

Agar tidak muncul peringatan email dan database tidak terkunci setelah 30 hari, buka console.firebase.google.com → pilih Realtime Database → tab Rules, lalu pasang aturan aman berikut: 

{
  "rules": {
    "wfm_database": {
      ".read": true,
      ".write": true
    },
    "wfm_audio": {
      ".read": true,
      ".write": true
    },
    "$other": {
      ".read": false,
      ".write": false
    }
  }
}

Klik tombol Publish (Publikasikan) di kanan atas console Firebase. Database akan aman permanen dan sinkronisasi 24/7 tetap lancar tanpa batas waktu!

Gunakan tombol "Bersihkan Cache" jika masih ada nama karyawan lama/dummy yang nyangkut di browser HP Anda.

Buka Spreadsheet

Sistem otomatis menyinkronkan data secara realtime ke Google Spreadsheet sesuai gudang yang aktif.

  1. Buka file Google Spreadsheet Target MBI.
  2. Di menu atas Google Sheet, klik Ekstensi (Extensions) → Apps Script.
  3. Hapus semua kode lama di editor, lalu klik tombol "Salin Kode Apps Script" di bawah dan Paste (Ctrl + V) ke Apps Script, lalu klik Simpan.
  4. PENTING: Otorisasi Izin Akses (1 Kali)
    Di atas editor Apps Script, pilih fungsi testManualSync dari dropdown lalu klik Jalankan (Run).
    Akan muncul popup "Otorisasi Diperlukan" → Klik Tinjau Izin → Pilih akun Anda → Klik Lanjutan (Advanced) → Klik Buka WFM Medika (tidak aman) → Klik Izinkan (Allow).
  5. Klik tombol biru Terapkan (Deploy) di pojok kanan atas:
    • Jika baru pertama kali: Pilih Deployment Baru (New Deployment) → jenis Aplikasi Web (Web App).
    • Jika sudah pernah pasang: Pilih Kelola Penerapan (Manage Deployments) → Klik ikon pensil Edit → Versi: pilih "Versi Baru" (New Version).
    • Jalankan sebagai: Saya (email Anda).
    • Yang memiliki akses (Who has access): WAJIB pilih "Siapa saja" (Anyone).
  6. Klik Terapkan (Deploy), salin URL Web App yang berakhiran /exec, tempelkan ke kolom di atas, lalu klik Tes Koneksi & Simpan & Aktifkan.
*Format otomatis sesuai ID Google Sheet masing-masing
